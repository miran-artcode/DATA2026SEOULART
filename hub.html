학생 허브

무엇을 해볼까요?

만들기 · 배우기 · 나누기 — 어디서든 ⓘ 설명과 💡 아이디어를 누르면 도움말이 떠요.

🎨 만들기 — 단계별 여정

기초(색·데이터)에서 시작해 소리 → 내 삶 → 사회로 넓혀 가는 4단계 여정이에요.

1단계 · 기초

색 군집 스튜디오 🎨

명화를 K-means로 분석해 대표색 점으로 치환하고, 마우스·소리로 ‘연주’하는 인터랙티브 작품.

 1단계 · 기초

데이터 점 스튜디오 ✨

우리 데이터를 점의 크기·속도·방향(벡터)·밀도로 변환해 ‘춤추는 점’ 미디어아트로.

 2단계

소리를 데이터로 🎤

녹음·오디오에서 음량·리듬·음색 특징을 뽑아 시계열 데이터로(아빠 코골이 샘플 포함).

 3단계

내 삶을 데이터로 🧑

‘오늘 가장 즐거운 순간’ 사진·챗봇 대화를 데이터로 — 무엇을 셀지 내가 정해요.

 4단계

사회문제 프로젝트 📣

기후·불평등·동물권… 공공데이터를 찾아 정제해 작품으로. 미술이 사회적 발언이 됩니다.

🔬 분석 · 렌즈 · 비평 (도구)

만든 작품을 깊이 들여다보고, 다른 ‘분석의 눈’으로 다시 보고, 비판적으로 읽는 도구들이에요.

분석 도구

알고리즘 분석실 🔬

한 그림을 7가지 알고리즘으로 분석 — 차트 + 재창조 + 한계 + 해석 메모.

 AI 렌즈

객체 감지 · AI의 눈 🤖

브라우저 AI(COCO-SSD)가 사진 속 사물을 찾아 점·데이터로. AI가 ‘무엇을 못 보는지’도 함께 봐요.

 비평

데이터 비평 읽기 🔍

차트의 ‘수사’를 폭로하고 질문 3층위(사실→해석→가치)로 비평해요.

📚 배우기 · 🤝 나누기

알고리즘 배움터

K-means·히스토그램·노탄·에지·중앙값분할·모자이크·구도. 쉬운→깊은 설명.

전시 갤러리

친구들 작품을 감상하고 구조화된 피드백을 남겨요.

분석 퀴즈 🎯

그림을 분석해 출제하고, 친구 문제를 맞혀 순위를 겨뤄요.

작업 노트

과정·버전·성찰을 기록 — 그대로 포트폴리오가 됩니다.

오늘의 탐구 문제 ⓘ

  1. K(또는 매핑)를 바꾸면 작품의 구조는 어떻게 달라지나?
  2. 어떤 설정이 원작/주제의 의도를 가장 잘 보존하나?
  3. 점 개수·밀도를 바꾸면 정보량·감정 전달이 어떻게 달라지나?
  4. 소리·마우스 인터랙션이 관람 경험을 어떻게 바꾸나?
