# 그림이 분해되어 다시 연주되다 · 데이터 미디어아트 스튜디오

> **보이지 않는 질서의 시각화 — 데이터, 3D 조각이 되다**
> 명화·작품 이미지를 업로드하면 **여러 알고리즘으로 분석**하고, 학생이 **의도와 조작 설정**을 더해
> **인터랙티브 제너러티브 미디어아트**로 변환해 작품을 만드는 수업용 웹 도구입니다.
>
> 서울미술고등학교 · AIEDAP — 2022 개정 교육과정(미술·정보) AI 융합수업 「그림이 분해되어 다시 연주되다」 지원 도구.

브라우저만 있으면 됩니다. 설치·서버·계정 없이 **`index.html`을 열면 바로 실행**됩니다.

---

## 무엇을 할 수 있나요

1. **이미지 입력** — 업로드 / 드래그&드롭 / 데모 이미지(석양·추상·바다숲, 저작권 걱정 없음).
2. **여러 방법으로 분석**
   - **K-means 색 군집화**: 그림의 색을 대표색 **K개**로 요약 → 팔레트 + 비율(%).
   - **색공간 선택**: RGB / **LAB**(사람 눈에 가까운 거리, 심화).
   - **샘플링(점 생성) 전략**: 무작위 / 밝은영역 / 어두운영역 / **윤곽(에지·Sobel)**.
3. **점(입자)으로 치환** — 점 개수 **N**, 크기, 색 모드(대표색/원본색)로 "해상도이자 표현 전략" 설계.
4. **움직임 설계** — 복귀력(집중)·진동·잔상(트레일)·발광, 그리고 **3D 조각**(밝기 → 깊이) 모드.
5. **인터랙션 설계**
   - **마우스**: 밀어내기 · 끌어당기기 · 부풀리기 · 흩뿌리기 · 클릭 폭발.
   - **마이크(소리)**: 볼륨 → 진동·확산·크기, **주파수(저·중·고음) → 밝기별 색 군집 반응**.
     («그림이 소리로 다시 연주되다»)
6. **프리셋** — 점묘화 / 살아있는 캔버스 / 소리로 연주 / 성운·해체 / 3D 조각.
7. **내보내기(수업 제출물)** — PNG 이미지, **WebM 영상 녹화**, 팔레트 복사,
   **분석 리포트·인터랙션 설계서(.md)**(부록 A·B 자동 작성), 설정 저장/불러오기(JSON).

## 데이터 파이프라인 (수업의 흐름 = 코드의 구조)

```
이미지 ─▶ 전처리(리사이즈·색공간) ─▶ 픽셀 색 데이터 추출
      ─▶ K-means 군집화(대표색 K개 + 비율)
      ─▶ 점 샘플링(무작위 / 밝기 / 윤곽 가중)  ─▶ 점 리스트(N개: 위치·대표색·밝기)
      ─▶ p5.js 렌더링 + 마우스/마이크 인터랙션  ─▶ 인터랙티브 미디어아트
```

- `js/kmeans.js` — K-means(군집/중심/거리) 알고리즘. k-means++ 초기화, **시드 기반 재현성**.
- `js/analysis.js` — 색공간 변환(RGB↔LAB), 픽셀 추출, Sobel 윤곽, 가중 샘플링, 데모 이미지.
- `js/audio.js` — Web Audio 마이크 입력(볼륨·저/중/고음). **음성은 저장하지 않음**.
- `js/particles.js` — 점(입자) 물리·인터랙션·렌더링(2D + 3D 투영).
- `js/app.js` — 화면·상태·이벤트·프리셋·내보내기·리포트.
- `vendor/p5.min.js` — p5.js 1.9.4(로컬 동봉 → 오프라인 동작).

> **수학·정보 연계**: "픽셀 전부 대신 핵심 색 K개로 요약" = 추상화의 실제 사례. K-means는 *모델/학습*,
> 그래픽 구현은 *일반 프로그래밍* — 역할을 구분해 'AI가 만든 작품'이 아니라
> **'AI 분석 결과를 해석·설계한 작품'**으로 학습 초점을 옮깁니다.

## 사용 방법

### 가장 쉬운 방법
1. `index.html`을 더블클릭해 브라우저로 엽니다. (인터넷 불필요)
2. 상단 **이미지 업로드** 또는 패널의 **데모 이미지**를 고릅니다.
3. **2 · 분석**에서 K·색공간·샘플링을 바꾸며 색 구조를 비교합니다. (팔레트 색을 클릭하면 그 군집 켜기/끄기)
4. **3~5 · 점/움직임/인터랙션**으로 표현과 반응 규칙을 설계합니다.
5. **7 · 내보내기**에서 이미지·영상·리포트를 저장해 제출합니다.

> 일부 브라우저는 보안상 `file://`에서 마이크를 막을 수 있습니다. 마이크가 필요하면 아래처럼 로컬 서버로 여세요.

### 로컬 서버로 실행(마이크·녹화 안정)
```bash
# 이 폴더에서
python3 -m http.server 8000
# 브라우저에서 http://localhost:8000 접속
```

### 온라인 전시(GitHub Pages)
1. 저장소 **Settings → Pages → Branch**를 `main`(또는 배포 브랜치)·`/root`로 설정.
2. 발행된 주소(예: `https://<계정>.github.io/<저장소>/`)를 QR로 만들어 전시.
   - HTTPS이므로 마이크·녹화가 정상 동작합니다.

### 수준별 환류
- **기초**: 교사가 **설정(JSON)** 을 배포 → 학생이 *불러오기*. 같은 이미지·같은 설정·같은 시드면 **점 데이터가 동일하게 재현**되어 분석 단계를 건너뛸 수 있습니다.
- **중간**: K·N을 직접 바꿔 비교(리포트 필수).
- **심화**: **LAB 색공간 · 윤곽(에지) 가중 샘플링 · 주파수 대역 분리** 인터랙션.

2. **어떤 K**가 원작의 분위기·의도를 가장 잘 보존하나?
3. **N(점 개수)**을 바꾸면 정보량·감정 전달이 어떻게 달라지나?
4. **소리·마우스 인터랙션**이 관람 경험을 어떻게 바꾸나?

## 윤리 안내
- **마이크 음성은 저장하지 않습니다.** 실시간 음량·주파수 값만 사용합니다.
- 원작 이미지의 **출처·라이선스를 반드시 표기**하세요(패널 8번 입력 → 리포트에 자동 포함). 가능하면 퍼블릭 도메인·공개 라이선스 이미지를 사용하세요.
- K-means의 색 요약은 **정답이 아니라 손실이 있는 근사·해석**입니다.
- 색 분석·요약은 **알고리즘(K-means)**, **의도와 규칙 설계는 학생**의 몫입니다.
